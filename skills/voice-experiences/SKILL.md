# Scenaro voice experiences

Use the Scenaro MCP tools. Read the connected account before any other call, then stay inside that company.

- Read applications, scenarios, conversations, collections, and analytics before proposing a change.
- Edit a draft or create a version only when the user asks for that change.
- Publish a version, synchronize a connector, or refresh analytics only after the user asks for that exact action. Refreshing analytics can spend credits.
- If a tool is refused, the connection does not have that permission. Ask the user to grant it. Do not look for another company.
